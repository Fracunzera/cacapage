# data/curated

Datos curados a mano, versionados. Ejemplos de lo que va a haber:

- `categorias.json`: categorías de lugar publicables (whitelist) y su mapeo
  desde tags de OSM.
- [`logros.json`](logros.json): catálogo de logros. Por ahora tiene solo
  "Bautismo de Porcelana" (primer registro); después se suman "Las YPF de la
  Ruta 3" con la lista curada de estaciones, el baño ajeno sin papel, etc.
- [`medallas.json`](medallas.json): **(i3)** una medalla cada 5 registros, con
  nombre (DESIGN.md §17).
- `feriados-ar.json`: feriados nacionales y provinciales (Santa Cruz).
- `lugares-overrides.json`: revisión humana de cada baño probable importado de
  OSM (excluir el "Almacén" etiquetado como supermercado, las salitas
  barriales, duplicados) y fichas de la recorrida de sembrado. Ver SEEDING.md.

Salvo `logros.json` y `medallas.json`, sin contenido todavía.
